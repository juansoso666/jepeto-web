```bash
1. Fusionar mejoras en GitHub

2. Activar GitHub Pages  
   └─ Settings → Pages → main/docs → Save

3. ¡LISTO! Tu sitio estará en:
   https://juansoso666.github.io/jepeto-web/
```

📖 **Guía detallada:** [LANZAMIENTO_RAPIDO.md](./LANZAMIENTO_RAPIDO.md)

---

### Opción 2: Con Dominio Personalizado (jepeto.es)

```bash
1. Seguir Opción 1

2. Comprar dominio jepeto.es (~€10/año)
   └─ Dondominio, Namecheap, GoDaddy

3. Configurar DNS
   └─ Añadir registros A y CNAME

4. En GitHub Pages → Custom domain: jepeto.es

5. Esperar 24-48h para DNS
```

📖 **Guía completa:** [GUIA_DESPLIEGUE.md](./GUIA_DESPLIEGUE.md)
