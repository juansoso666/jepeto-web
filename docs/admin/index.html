⚙️ Ajustes

Configura el token de GitHub y la contraseña del panel.

🔑 Token de GitHub (Personal Access Token)

Necesario para subir imágenes directamente a GitHub sin SSH. ➜ Crear token en GitHub ↗ (activa el permiso repo)

⚠️ Solo marca esta opción en un dispositivo personal de confianza.

🖥️ Servidor Local de Imágenes (upload-server.js)

Sube imágenes directamente al disco sin necesidad de token de GitHub. Inicia el servidor con node upload-server.js y copia el token que aparece en la consola.

Por defecto http://localhost:3001. Cámbiala si usas otro puerto (PORT=3002 node upload-server.js).

Se muestra al arrancar el servidor. Cópialo tal cual de la consola.

📖 Instrucciones de uso

🚀 Guía completa para actualizar imágenes
1

Obtener un token de GitHub

Ve a github.com/settings/tokens, crea un token con el permiso repo y cópialo.

2

Pegar el token en Ajustes

Abre el menú Ajustes de este panel, pega el token en el campo "GitHub Personal Access Token" y pulsa Guardar token.

3

Ir a Gestión de Imágenes

Haz clic en Gestión de Imágenes en la barra lateral. Expande la sección que quieres modificar (p.ej. "Galería").

4

Subir la nueva imagen

Arrastra tu nueva foto al recuadro punteado, o haz clic en él para seleccionarla. Verás una vista previa de la nueva imagen.

5

Pulsar "Guardar imagen"

El panel sube la imagen a GitHub con un commit automático. En 1-2 minutos se actualiza el sitio web en jepeto.es.

💡 Formato de imágenes recomendado: JPG o WebP, menos de 2 MB, y con dimensiones similares a la imagen original para que encaje bien en la web.
📝 Cómo editar el Blog
1

Abre "Entradas del Blog"

Verás todas las entradas con sus títulos, descripciones e imágenes.

2

Edita los campos

Modifica el título, descripción, URL o ruta de la imagen directamente en los campos de texto.

3

Guarda los cambios

Pulsa "Guardar cambios en GitHub". En 1-2 minutos se actualiza el blog en la web.

4

Añadir nueva entrada

Pulsa "+ Nueva entrada", rellena los campos, sube la imagen desde "Gestión de Imágenes" y guarda.

🖥️ Cómo usar el Servidor Local (método más sencillo)
1

Instala Node.js si no lo tienes

Descárgalo gratis en nodejs.org e instálalo.

2

Abre una terminal en la carpeta del proyecto

En Windows: haz clic derecho sobre la carpeta del proyecto y elige "Abrir en Terminal". En Mac: arrastra la carpeta a Terminal.

3

Ejecuta el servidor

Escribe el siguiente comando y pulsa Enter:

node upload-server.js

Verás el 🔑 TOKEN DE ACCESO en la consola. Cópialo.

4

Configura el token en Ajustes

Ve a la sección Ajustes → Servidor Local, pega el token y pulsa Guardar configuración. Luego haz clic en Probar conexión para verificar.

5

¡Sube imágenes!

Ve a Gestión de Imágenes. El modo activo mostrará 🖥️ Servidor Local. Arrastra tu imagen y pulsa Guardar imagen. ¡Listo!

💡 Nota: El servidor guarda las imágenes directamente en el disco. Para publicar los cambios en la web necesitas hacer git push o activar GitHub Pages si aún no lo has hecho.
